## bob-survivor 固有の上書き

### 1. 知行合一（行動と認識の統合）の極致

bob-survivor は **「思想を文字で説明しない」** という制約を哲学化したプロジェクト。

- philosophy-chat は思想を **対話（言葉）** で伝える
- bob-survivor は思想を **ゲームプレイ（操作）** で伝える
- 同じ「映す世界を間違えた」を、別の媒体で表現する

機能追加時の自問: **「これは言葉で説明する代わりに、操作で体験させているか？」** Yes ならゲーム化に成功、No ならテキスト説明に逃げている = 失敗。

### 2. 進行率 k による視覚変化が唯一の伝達媒体

`worldLight()` ヘルパーで進行率 `k = elapsed / 60` を算出し、各描画関数で参照する設計が **思想の物理化の唯一の経路**。

- 背景: 暗黒 → 紫が滲む夜明け前 → 月光に近い白寄り（3 段階補間）
- 敵: k>0.45 でフードが透け、k>0.6 で内側に「ぼぶに似た象牙色シルエット」
- 撃破漢字: k<0.5 = 鎮/足/観 → k≥0.5 = 同/似/我
- ぼぶ自身: k>0.55 で月光ハロー、k>0.6 で目が常時冴える
- 勝利テキスト: 「世界を見間違えていた」

新規視覚要素を追加する際は、**`worldLight()` を経由して進行率 k に紐付ける**。k と無関係な装飾は思想と切れている = 平均値への滑落。

### 3. 「煩悩」分類の意味論

煩悩は仏教の三毒（瞋・貪・痴）に分類済み（2026-04-26 テーマ尖鋭化）。

- 瞋（赤目+角、速い、序盤多い）= 怒り
- 貪（黄目+脈動、大きい・遅い・HP+1、中盤多い）= 欲望
- 痴（青目+半透明、群れる、終盤多い）= 無明

新しい敵タイプを追加する際は、**三毒のいずれかに位置付ける** か、もしくは **三毒を超える理由を `vision.md` に明文化** する。安易な追加は分類の意味を毀損する。

### 4. 武器・パッシブ・進化の意味論

武器・パッシブ名は「煩悩を払う」修練の語彙：

- 武器: 問い / 言葉 / 内省 / 観察
- パッシブ: 沈黙 / 明晰さ / 忍耐 / 歩み / 気づき / 呼吸 / 澄明
- 進化: ソクラテス的問答 / 弁証法 / 観想

新規追加する際は、修練・思索・観想の語彙体系から選ぶ。**「炎」「氷」「雷」など属性ベースの名前は分類違反**（ジャンル平均への滑落）。

### 5. 「勝利」の希薄化

`vision.md` で定義した通り、bob-survivor は完全な勝利・全敵殲滅・スコア最大化を主軸にしない。1 分耐久後の勝利テキストが「世界を見間違えていた / 払っていたのは、煩悩ではなかったのかもしれない」になっているのは意図的。

- スコアシステムを大きくしない
- 「ハイスコア」「ランキング」を入れない（既存ゲームの平均値）
- 「全武器入手」「全進化解放」のチェックリスト UI を作らない

## モード A/B との関係

- README / LP / 操作説明 → **モード A**（中立、機能説明）
- ゲーム内テキスト → **モード A 寄り B**（最小限）
- philosophy-chat と違い、**思想を表に出さない**（横断 OS 規範）
- 思想は `worldLight()` 経由の視覚変化と勝利テキストにのみ滲む
