# bob-survivor Vision

> bob-survivor が提供すべき変容的体験 — プレイヤーがプレイ後、世界の見え方がどう変わるべきか。

## 核（1 段落）

bob-survivor は「煩悩を倒すアクションゲーム」ではない。**プレイヤーが 1 分間、敵を払い続けた末に、敵だと思っていたものが自分自身の輪郭だったと気付くゲーム**。最初は瞋（赤目+角、明確な敵）から始まり、進行率 k が上がるにつれて敵のフードが透け、内側に「ぼぶに似た象牙色シルエット」が浮かび、k>0.55 でぼぶの周囲に淡い月光ハロー、撃破時の sfx は払う音から静謐な余韻に変調する（要素 11 worldLight 経由 sfx 再文脈化）。次プレイ起動時は累計撃破がヴィネット強度に微浸透（要素 1 lifetimeTint）。勝利テキストは「世界を見間違えていた / 払っていたのは、煩悩ではなかったのかもしれない」。**プレイヤーは敵を倒した実感ではなく、敵が消えた違和感とともに席を立つ。**

## プレイヤーがプレイ前に持っている前提

- 「Vampire Survivors のオマージュ = 弾幕系で気持ちよく敵を吹き飛ばす」
- 「ローグライトのビルド構築の快感が core」
- 「ゲームには明確な敵がいる」

## プレイヤーがプレイ後に到達すべき認識

- 「敵だと思っていたのは、自分の解釈だった」
- 「Vampire Survivors のジャンル文法を借りて、別のことを言っていた」
- 「これはゲームの形をした思想の伝達装置だった」

## このプロダクトの特殊な位置付け

> **L0 思想（裏）と L3 Procedural Rhetoric（表現）が直結している唯一のプロジェクト。**

cross_project_philosophy の「映す世界を間違えた」を、テキストで説明せずに **ゲームメカニクスのみで体験させる**。これは Procedural Rhetoric（[[自律型開発スタジオの5層モデル]] L3）の極致であり、philosophy-chat とは別の方法（言葉ではなく操作）で同じ思想を伝える。

知行合一（行動と認識の統合）の最高例: プレイヤーは「煩悩を払う」操作をしているつもりが、その操作が **「自分自身の輪郭を払い直している」** ことに後から気付く。テキスト説明ゼロ、メカニクスのみで成立。

## 避けるべき方向

- 既存 Vampire Survivors 系の「パワーファンタジー」「火力の暴力」枠への自己分類
- 撃破時の漢字フロート表示など、テーマを **明示的に文字で説明する** 演出（試作後に削除済み、`anti_patterns.md` カテゴリ 1 第 5 項で再発禁止登録、Gamma N=3 で復活案を L0 違反として却下、2026-05-09）
- 「ぼぶの哲学を体験するゲーム」と LP に書く（説教調、モード A 違反、テーマ説明過多）
- 経験値バーの大型化、レベルアップ演出の派手化（成長の達成感に焦点が移る、思想が消える）
- 完全な勝利・全敵殲滅・スコア最大化を主軸にする（テーマと矛盾、L0 鉄則違反）
- 「映す世界を間違えた」を LP / README / 操作説明に文字で書く（裏に置く原則違反）

## 変容の証拠（プレイテスト的検証ポイント）

プレイヤーが 1 プレイ（1 分）終えた直後、次のいずれかを自発的に言ったら成功：

1. 「最後の敵、ぼぶに似てなかった？」
2. 「これ、煩悩を払うゲームじゃないよね」
3. 「勝ったのか負けたのかよくわからない感じ」（意図通りの違和感）
4. 「Vampire Survivors と同じ操作なのに、なんか違うことやってた気がする」

逆に「気持ちよかった」「サクサクで楽しい」「ビルドが面白い」しか出なかったら、変容的体験が機能していない = ジャンルの平均値に堕ちている = L4 Playable Gate で差し戻し。

ただし「気持ちよさ」「ビルド構築の快感」自体は (b) 路線として MVP 着手済みで否定しない。**気持ちよさを入口に、終盤で輪郭を反転させる** のが設計意図。気持ちよさだけで終わったら失敗。

## モード A/B との関係

- README / LP / 操作説明 → **モード A**（中立、機能説明、footer に "by ぼぶ" + 1 行）
- ゲーム内テキスト（勝利テキストなど）→ **モード A 寄り B**（最小限の言葉、説明調を避ける）
- philosophy-chat とは違い、**ゲーム本体は思想を表に出さない**（横断 OS の規範に従う）
- ぼぶ（プレイヤーキャラ）の SVG 表現と進行率 k による視覚変化が、思想の唯一の媒体
